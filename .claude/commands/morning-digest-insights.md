# Morning Digest インサイト抽出

morning-digest（http://localhost:3000）で収集した記事URLを読み込み、今日身につけるべき技術知見を抽出します。

## 使い方

```
# morning-digestでコピーしたテキストを貼り付けて実行
/morning-digest-insights

## Swift (21件)
■ 記事タイトル
  https://...
```

または `$ARGUMENTS` に記事リストのテキストを渡す。

引数がない場合は、ユーザーに morning-digest（http://localhost:3000）で記事を取得してテキストをコピーするよう案内する。

## 実行手順

1. **入力の受け取り**
   - `$ARGUMENTS` またはユーザーの貼り付けテキストから記事URLリストを取得
   - ジャンル（AI・Frontend・Swift・Kotlin など）とタイトル・URLのペアを抽出

2. **記事の読み込み**
   - WebFetch ツールで各URLのコンテンツを取得（並列実行で効率化）
   - 取得できない場合はタイトルから内容を推測

3. **知見の抽出と整理**
   - 実務で使える知見を抽出
   - ジャンルをまたいだ横断的なトレンドも把握

## 出力形式

```
🧠 今日身につける知見

### [知見タイトル]
**背景・理由**: なぜこれが重要か
**実務での使い方**: 具体的な活用法
**落とし穴**: 注意点・よくある間違い
**参考**: [記事タイトル](URL)
```
