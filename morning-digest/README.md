# 🌅 Morning Digest

毎朝のエンジニア情報キャッチアップツール。キーワードで最新記事を収集し、URLを一括コピーしてAIに読み込ませるところまでをサポートします。

## 起動方法

```bash
cd convenience-tools/morning-digest
npm install   # 初回のみ
npm run dev
```

ブラウザで http://localhost:3000 を開く。

## 毎朝の使い方

### 1. キーワードを入力して記事を取得

画面上部のキーワード入力欄にトピックを入力して `Enter` または `+` ボタンで追加。

```
例: Swift, Kotlin, Claude, Cursor, iOS, AI
```

「🔍 最新を取得」ボタンを押すと Zenn・Qiita・Hacker News から最新記事を取得。

キーワードは自動保存されるので、翌日以降は「🔍 最新を取得」を押すだけでOK。

### 2. 記事を確認してURLをコピー

取得後にコピーパネルが表示されます：

| ボタン | 用途 |
|--------|------|
| 📋 URLを一括コピー | ClaudeやChatGPTにURLを読み込ませる |
| 📋 タイトル+URLを一括コピー | タイトルとURLをセットでコピー |
| 🤖 AIプロンプト付き | 要約プロンプト込みで丸ごとコピー |

ジャンル別（AI・Frontend・Swift・Kotlin…）のセクションヘッダーをホバーすると、そのジャンルだけのコピーボタンも出てきます。

### 3. AIで知見を抽出する（メイン活用）

コピーしたテキストを **VS Code Copilot Chat** に貼り付けて `/morning-digest-insights` を使う。

```
/morning-digest-insights

## Swift (21件)
■ 記事タイトル
  https://...
...
```

**出力形式:**
```
🧠 今週身につける知見
  各知見に「背景・理由 / 実務での使い方 / 落とし穴 / 参考URL」が付く

📐 判断基準チートシート
  〇〇 vs △△ の選択基準を表形式で

⚠️ 今すぐ確認すべきリスク
  バージョン変更・非推奨化・セキュリティ情報（URL付き）
```

## 期間フィルター

ヘッダーのピルで記事の期間を絞れます：

```
1日 / 3日 / 1週間（デフォルト）/ 1ヶ月 / 全期間
```

設定はブラウザに保存されます。

## 音声読み上げ

⚙️ アイコンから音声設定を開けます：

- **Web Speech API**（デフォルト）: macOS の Kyoko ボイスで読み上げ
- **VOICEVOX**（オプション）: ローカルで VOICEVOX を起動している場合はずんだもん等が使える

## データキャッシュ

取得した記事は `data/articles.json` にキャッシュされます（60分で再取得）。
